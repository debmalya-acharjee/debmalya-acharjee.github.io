# Debmalya Acharjee — Europe-focused SRE / DevOps Portfolio

Astro + TypeScript portfolio designed around engineering evidence rather than a generic resume page.

## Main content file

Almost all personal content is managed from:

```text
src/data/portfolio.ts
```

Update that file for:
- headline and location
- impact metrics
- focus areas
- skills
- experience
- projects and case-study content
- certifications, education and languages

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:4321`.

## Resume

Place the preferred public CV at:

```text
public/resume/Debmalya-Acharjee-Resume.pdf
```

## Before publishing

Update any project repository links that should point to a more specific repo.
